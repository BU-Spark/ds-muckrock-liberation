# merge_by_year

A test: merging the 32 annual tables of each year into one CSV (FY2008-2025, agency level).

`data_type_map.csv` maps the data type numbers 01-32 (the order on foia.gov's data page) to the official file names and to the column prefixes in `output/FOIA_agency_FY2008-2025.csv`. Exemption 3 statutes (06) are in `output/exemption_statutes_FY2008-2025.csv`.
